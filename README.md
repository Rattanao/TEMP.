# Revised Temp

แก้อุณหภูมิตู้เย็นในไฟล์ CLIST (.txt) โดยตัดตัวเลขหลักสุดท้ายก่อน `C` ออก 1 หลัก แล้วบันทึกเป็น `Revised temp.txt`

| เดิม | ใหม่ |
|---|---|
| `S-20C` | `S-2C` |
| `S-10C` | `S-1C` |
| `S-180C` | `S-18C` |
| `S20C` | `S2C` |
| `S50C` | `S5C` |
| `S0C` | `S0C` (ไม่แก้ไข เพราะมีตัวเลขหลักเดียว) |
| `S` | `S` (ไม่แก้ไข เพราะไม่มีตัวเลข) |

- ช่องอุณหภูมิอยู่ที่ตัวอักษรที่ 145 ของแต่ละบรรทัด (ต่อจาก Size/Type เช่น `45R1  8  Q `)
- ตัวอักษรที่หายไปจะถูกแทนด้วยช่องว่าง ทุกบรรทัดจึงยาวเท่าเดิม ข้อมูลคอลัมน์ถัดไป เช่น น้ำหนัก `KGM` ยังอยู่ตำแหน่งเดิม
- ไม่แก้ไขส่วนอื่นของไฟล์ รวมถึงการขึ้นบรรทัดใหม่ (CRLF)

## วิธีที่ 1: ใช้หน้าเว็บ (`index.html`)

1. เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge (ดับเบิลคลิกได้เลย ไม่ต้องติดตั้งอะไร) หรือเปิดผ่าน GitHub Pages ถ้าเปิดใช้งานไว้
2. ลากไฟล์ CLIST มาวางในช่องเส้นประ หรือคลิกเพื่อเลือกไฟล์
3. กด **แก้ไขอุณหภูมิ**
4. ตรวจสอบตารางผลการแก้ไข (บรรทัด เบอร์ตู้ Size/Type ค่าเดิมและค่าใหม่) กด "ไม่แก้ไข … บรรทัด" เพื่อดูตู้ที่ไม่ได้แก้
5. กด **บันทึก Revised temp.txt** ไฟล์จะอยู่ในโฟลเดอร์ Downloads
6. ถ้าต้องการรายงานเป็น Excel ให้กด **ดาวน์โหลด Excel** จะได้ไฟล์ `Revised temp.xlsx` จัดรูปแบบพร้อมพิมพ์ (A4 แนวตั้ง) มี 2 ชีต
   - **ผลการแก้ไข**: หัวรายงาน (ชื่อไฟล์ วันที่ จำนวนบรรทัด) ตารางค่าเดิม (ขีดฆ่า) และค่าใหม่ (สีเขียว) พร้อมตารางสรุปจำนวนตามค่าอุณหภูมิ
   - **ไม่แก้ไข**: ตู้ที่อุณหภูมิเป็น `S0C` หรือ `S` พร้อมเหตุผล

ไฟล์ถูกอ่านและแก้ในเบราว์เซอร์เท่านั้น ไม่ถูกส่งออกไปที่ใด

## วิธีที่ 2: ใช้คำสั่ง Python (`revised_temp.py`)

ต้องมี Python 3.8 ขึ้นไป

```bash
python revised_temp.py "CLISTHLCH_xxxx.txt"
```

ผลลัพธ์จะถูกบันทึกเป็น `Revised temp.txt` ในโฟลเดอร์เดียวกับไฟล์ต้นฉบับ และแสดงรายการที่แก้ไขบนหน้าจอ ถ้าต้องการตั้งชื่อไฟล์ผลลัพธ์เอง ให้ใส่ชื่อเป็นค่าที่สอง

```bash
python revised_temp.py "CLISTHLCH_xxxx.txt" "ผลลัพธ์.txt"
```
